# ping-pong-mmrs

Платформа для проведения соревновательных матчей по настольному теннису (ping pong) с рейтинговой системой.

Пользователи регистрируются в системе и получают стартовый рейтинг (MMR) — 1000 очков. После этого они могут участвовать в матчах против других игроков. Рейтинг обновляется по результатам игр и отражает текущий уровень игрока.

## Как проводится игра

Игра проводится между двумя зарегистрированными пользователями платформы в рамках выбранного формата (bo1, bo3 или bo5).

### 1. Создание игры

- Рефери создаёт игру, указывая:
    - участников матча;
    - формат (bo1, bo3, bo5).
- После создания игра получает статус «Ожидает начала».

### 2. Начало игры

- Игра переводится в статус «В процессе».
- Игроки начинают матч в соответствии с выбранным форматом.

### 3. Проведение сетов

- Игра состоит из последовательности сетов.
- После завершения каждого сета рефери фиксирует его результат в системе.
- Счёт обновляется автоматически на основе введённых данных.

### 4. Определение победителя

- Игра продолжается до тех пор, пока один из игроков не достигнет необходимого количества побед в сетах:
    - bo1 — 1 выигранный сет;
    - bo3 — 2 выигранных сета;
    - bo5 — 3 выигранных сета.
- После выполнения условия игра завершается.

### 5. Завершение игры и обновление рейтинга

- Игра получает статус «Завершена».
- Система автоматически:
    - рассчитывает изменение MMR;
    - обновляет рейтинг обоих игроков.

### 6. Отмена игры

- Игра может быть отменена рефери до её завершения (например, в случае ошибки создания или невозможности продолжения матча).
- В случае отмены:
    - игра получает статус «Отменена»;
    - изменения рейтинга (MMR) **не применяются**;
    - рейтинги игроков остаются без изменений.
